# 华为云 Ubuntu x86 离线部署指南（Docker 离线包）

## 1. 前置条件（华为云服务器上执行一次）

```bash
# 已装 Docker 则跳过
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker
```

## 2. 上传并加载镜像

把 `watermarks-remover-1.0-amd64.tar.gz` 传到服务器（scp 或华为云 OBS 中转）：

```bash
scp watermarks-remover-1.0-amd64.tar.gz root@<服务器IP>:/opt/
```

服务器上加载：

```bash
cd /opt
gunzip -c watermarks-remover-1.0-amd64.tar.gz | docker load
# 输出: Loaded image: watermarks-remover:1.0-amd64
```

## 3. 运行

**无鉴权（仅内网/安全组限制来源 IP 时）：**

```bash
docker run -d --name watermarks --restart unless-stopped -p 8080:8080 watermarks-remover:1.0-amd64
```

**开启 HTTP Basic Auth（有公网访问时强烈建议）：**

```bash
docker run -d --name watermarks --restart unless-stopped -p 8080:8080 \
  -e AUTH_USER=admin -e AUTH_PASS='改成你的强密码' \
  watermarks-remover:1.0-amd64
```

浏览器访问 `http://<服务器IP>:8080`，弹出账号密码框，输入即用。
注意 `AUTH_PASS` 含 `$` 等特殊字符时用单引号包裹。

**华为云安全组**：只放行 8080 端口（TCP），来源建议限制为自己的常用 IP；80/443/22 按需。

## 4. 常用运维命令

```bash
docker logs -f watermarks          # 看日志
docker restart watermarks          # 重启
docker stop watermarks && docker rm watermarks   # 停止并删除容器（镜像保留）
docker update --memory 1500m --memory-swap 1500m watermarks  # 限制内存 1.5G（2G 机器建议）
```

`--restart unless-stopped` 已含开机自启，无需额外配置 systemd。

## 5. 镜像内容与限制

- 容器内：API(:8765 仅容器内部) + Web UI(:8780 仅容器内部) + nginx(:8080 对外)
- 单文件上传上限 100MB（环境变量 `WATERMARKS_MAX_INPUT_BYTES` 可调）
- 图片/视频的溯源清理、写入拍摄元数据功能完整可用
- 不含：画面可见水印去除（需 GPU/ffmpeg）、SynthID 检测（开源无模型）
